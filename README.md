# やること（todo）

仕事・プライベート・トレードなどの「やること」を区分ごとに書き留める、個人用の小さなリスト。
1枚の HTML・ビルド不要。`index.html` をブラウザで開くだけで動きます。スマホ（ホーム画面に追加）と Mac で同じ中身を見られます。

公開 URL: https://hoshi2.github.io/todo/

## 画面

- **上の切替** — 区分。初期は 仕事（不動産）／プライベート／トレード／後回し／買うもの。右端の鉛筆で 名前変更・追加・並べ替え・削除（中身が残っている区分は消せない）
- **入力欄** — 打って Enter（スマホは「追加」）で今の区分に入る。新しいものが上
- **1件** — 丸を押すと完了。文字を押すと 書き直し／区分を移す／削除
- **完了 n件** — 下に畳む。開くと「戻す」（丸を押す）「×」「完了をすべて消す」
- **設定（歯車）** — 端末間の同期、JSON のバックアップ／復元、版番号。これだけ

見た目（色・字体・角丸）は [ぼぶる](https://github.com/hoshi2/bobru) と同じ定義。暗い／明るいは端末の設定に従います。

## データの扱い

- 保存はブラウザの `localStorage`（キー `todo_v1`）。サーバーへは送りません
- 1件 = `{id, text, cat, done, doneAt, created, _m}`。区分 = `{id, name, order, _m}`。`_m` は最後に変えた時刻
- **端末間の同期**（ぼぶる・ロイログ・お金・習慣と同じ方式）: 設定で自分の Firebase（Firestore）の設定と合言葉（同期コード）を入れると、collection `todo` のドキュメント `{合言葉}` に中身を丸ごと1件置き、変えるたびに自動で送り、相手の変更は自動で届く。合わせるときは 1件ごとに `_m` が新しい方が勝ち、消したものは `deleted` の墓標で相手側でも消える
- 公開ページ（hoshi2.github.io）では ぼぶる と保存領域が同じなので、「ぼぶると同じ設定と合言葉を使う」ボタン1つで接続できる（鍵の貼り直し不要）。手で決める合言葉は 20 文字以上
- この repo にはコードだけ。やることの中身・鍵は入れない（Public）

## 開発

- 依存なし。テストは Playwright（開発時だけ）: `npm i -D playwright && npx playwright install chromium && node tests/run.mjs`
- 画面の外から中身を確かめる入口: `window.__todo`（DB・mergeDB・addItem など）
- 共通ルールは `hoshi2/bob-bridge`（`AGENTS.md`）
